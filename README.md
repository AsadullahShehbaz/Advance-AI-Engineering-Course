## About

A practical, code-first course on the latest LangChain. You learn to build AI agents from scratch, add retrieval (RAG), connect external tools, control agent behavior, manage memory, and move toward production-ready agentic applications.

**You will learn how to:**

- Build tool-using agents with `create_agent()`
- Implement a complete RAG pipeline
- Control agents with middleware, human-in-the-loop approval, and guardrails
- Add short-term and long-term memory with Postgres and Supabase
- Engineer context and connect agents to external services through MCP

**Who it's for:** developers with Python basics who want to move from simple LLM apps to production-grade agents.
