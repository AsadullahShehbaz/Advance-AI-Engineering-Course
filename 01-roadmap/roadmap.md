## Course Roadmap

```text
Foundations → Build with LLMs → Knowledge (RAG) → Production Agents → Agent Context & Integrations
```

### Stage 1: Foundations

1. `Intro to Agentic AI`: understand what agents are and how they differ from plain LLM applications
2. `Intro to LangChain`: explore the framework, its core building blocks, and setup
3. `Model Configuration`: choose and configure models and providers
4. `Prompt Engineering`: write prompts that make model behavior reliable

### Stage 2: Build with LLMs

5. `Structured Output`: get validated, predictable data instead of free text
6. `Tools`: let models call functions and external services

### Stage 3: Knowledge (RAG)

7. `What is RAG`: understand why models need external knowledge and how retrieval solves this problem
8. `RAG Implementation`: build a working retrieval-augmented generation pipeline

### Stage 4: Production Agents

9. `LangChain Agent`: build agents using `create_agent()`, state, streaming, and tool execution
10. `Middleware`: control agent execution using middleware, including summarization and human-in-the-loop approval
11. `Guardrails`: validate inputs and outputs to prevent unsafe or unwanted agent behavior

### Stage 5: Agent Context & Integrations

12. `Memory`: maintain conversation history and long-term information across interactions
13. `Runtime`: access runtime information, state, context, and execution capabilities
14. `Context Engineering`: manage the information provided to agents for better decisions and performance
15. `MCP`: connect LangChain agents to external tools and services through the Model Context Protocol

`By the end:` you will be able to build, control, and safely deploy tool-using, memory-aware LangChain agents that interact with external systems.
